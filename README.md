# RiaCoding güncelleme kanalı

RiaCoding için bağımsız dağıtım deposudur. Uygulama kaynak kodu bu depoda bulunmaz.

Hazır kurulum paketleri yalnız [Releases bölümünde](https://github.com/SupremeRia/RiaCoding-updates/releases) yayımlanır. SucukCenter güncellemeleriyle bağlantısı yoktur.

Henüz yayımlanmış kurulum paketi veya latest.yml yoktur. Çevrimiçi pilot geliştirme aşamasındadır; bu sayfa çalışan bir pilot yayını değildir.

Yayınlarda kurulum dosyası, blockmap, latest.yml ve SHA256SUMS.txt birlikte doğrulanır. Tamamlanmamış dosyalar taslakta kalır. Yayımlanmış sürümler sessizce değiştirilmez.

Bu depo yalnız README ve Release varlıklarını içerir. Kaynak geçmişi, işletme yedeği, parola ve gizli anahtar burada yayımlanmaz.
